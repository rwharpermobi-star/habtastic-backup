# GitHub Sponsors Plan

## Sponsor profile

### Short bio

Building HabTastic — a gamified habit tracker combining habits, rewards, progress, mobile features, and AI-assisted coaching.

### Introduction

HabTastic is an independent product focused on making consistency more engaging.

Sponsorship helps fund continued product development, infrastructure, testing, security, mobile development, and new features. The goal is to turn HabTastic into a polished, reliable habit-building platform that people genuinely enjoy using.

Sponsors are helping fund the work behind the product — not simply donating to an abandoned repository.
