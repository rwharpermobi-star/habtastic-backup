# Contributing to HabTastic

Thanks for your interest in HabTastic.

## Before opening an issue

Please check existing issues first. For bugs, include:

- What you expected to happen
- What actually happened
- Steps to reproduce it
- Browser/device and operating system
- Relevant screenshots or logs, with secrets and personal information removed

## Feature requests

Explain the problem the feature would solve, the proposed behavior, and why it would improve the product.

## Pull requests

For code changes:

1. Keep the change focused.
2. Follow the existing TypeScript/React conventions.
3. Run the relevant tests and type checks before submitting.
4. Do not commit secrets, service-role keys, credentials, tokens, or private user data.
5. Explain security-sensitive changes clearly in the pull request.

HabTastic uses automated production security verification, so changes affecting Supabase, RLS, RPCs, authentication, payments, referrals, economy data, or privileged operations should include appropriate tests.
